# Initial project framing

Date: 2026-08-10
Status: distilled discovery note

## Starting intent

The project should not be treated as merely a personal homepage. It is intended to become a long-lived home for Sebastian's public-facing personal work and thinking.

Known areas include:

- the personal website;
- GitHub presentation/profile;
- articles and essays;
- ideas and notes;
- future material that does not yet have a fixed publishing destination.

## Working model

Use the repository as the canonical project memory and source corpus. Treat individual publishing destinations as surfaces over that corpus.

Do not force an implementation roadmap yet. The immediate task is initialization and durable context. Future work should begin from a concrete objective supplied in a later conversation.

## Open questions

These are intentionally unresolved until there is a reason to decide them:

- Which content should live only in the repository versus be published?
- How should GitHub profile content relate to the website?
- What taxonomy should organize essays, notes, projects, and ideas?
- Which parts of the corpus should eventually become reusable structured data?
- Whether the current Astro information architecture should evolve as the corpus grows.
